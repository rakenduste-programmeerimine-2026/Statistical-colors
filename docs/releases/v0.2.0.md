# v0.2.0

Release from `develop-frontend` into `main`. This is the first tagged release; `main` before it is v0.1.0.

Scope: #90, #91 and #92 (milestone M3), merged into `develop-frontend` in PR #97. M3 itself is not complete; this is an interim release.

## Completed features

- **Results page, from the user test (#90):**
  - a readable summary;
  - a collapsible colour analysis;
  - confidence shown in words, never as "100 %";
  - Estonian tooltips on every colour term, with an accessible glossary.
- **3D colour space (#90):** shows the whole colour cloud by default, with hue, chroma and lightness filters in a collapsible panel.
- **Viewers (#90):** both viewers remember their background and offer the CIE L* 50 grey.
- **Colour names (#91):** every colour code in the app shows its nearest name from `color-name-list`, matched by ΔE in OKLab. The name list loads only when a name is shown.
- **Themes (#91):**
  - saved themes have names, and can be listed by name or by their colours' names;
  - the theme picker is a widget on the right edge of the page.
- **Upload (#91):** a clear drag-and-drop box for one image, and a primary process button.
- **Demo:** runs the server's real colour analysis on the study's colours, instead of a simulated one (P-045).
- **Gamut coverage:** the stub and the demo use the server's gamut coverage calculation (#74, P-044).
- **Algorithm docs (#92):** `docs/algorithms/` has formal models of every analysis step. Each page says what the local Lean runs prove and what was measured.

## Resolved issues

- #90, #91 and #92 are done. They are still open on GitHub, because closing keywords only work for merges into `main`. Close them when this release is merged.

## Bug fixes

These are all logged in `docs/bugs/README.md`:

- Trackpad zoom no longer jumps several levels per gesture.
- The colour count chosen on upload now reaches the heading, the 3D view and the demo.
- Table values stay on one line, the similarity bar stays inside its column, and alpha is readable.
- "Segupiksli sarnasus" reads only the blend entry.
- A zero ΔE or ΔL shows as words, not "0.000".
- The remaining colour codes have names, and closing the theme widget works correctly.
- Every colour term has a tooltip.
- The extension's PDF-limit test no longer times out under full-suite load.
